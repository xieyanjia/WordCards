# WordCards 單字卡學習系統

## 專案簡介

WordCards 是一個使用 C# Windows Forms 製作的單字卡學習系統，主要功能是讓使用者可以透過單字清單進行英文單字學習。系統會從文字檔讀取單字資料，並在畫面中顯示單字、音標與中文解釋，使用者也可以播放單字音檔來練習發音。

本專案除了基本的單字瀏覽與播放功能之外，也加入了「易忘單字」功能。使用者可以將不熟悉或容易忘記的單字加入易忘單字清單，日後可以透過「查看易忘單字」按鈕集中複習，提升學習效率。

## 專案功能

### 1. 單字卡顯示功能

程式會讀取 `WordCards.txt` 中的單字資料，並顯示在單字清單中。使用者點選單字後，畫面會顯示該單字的英文、音標與中文解釋。

### 2. 單字發音播放功能

當使用者選取單字時，系統會根據單字資料中的音檔路徑播放對應的發音檔。若找不到音檔，程式會在狀態列顯示提示訊息。

### 3. 自動播放功能

按下 `Play` 按鈕後，系統會自動依序播放單字清單中的單字。再次按下按鈕後，會停止自動播放。

### 4. 鍵盤操作功能

使用者可以透過鍵盤快速操作：

- 按下 `Enter`：播放下一個單字
- 按下 `Space`：重複播放目前選取的單字

### 5. 編輯單字功能

使用者可以雙擊單字清單中的單字，開啟編輯視窗。編輯視窗可以修改單字、音標、音檔路徑與中文解釋，儲存後會更新單字資料。

### 6. 加入易忘單字功能

當使用者覺得某個單字不熟或容易忘記時，可以按下「加入易忘單字」按鈕。系統會將目前選取的單字加入 `HardWords.txt`，作為日後複習使用。

### 7. 查看易忘單字功能

按下「查看易忘單字」按鈕後，系統會讀取 `HardWords.txt`，並只顯示易忘單字清單。再次按下按鈕後，會切換回全部單字清單。
